# Sliceverse LIV 3D — сборка

## Локально
Двойной клик по `start.cmd` (нужен Python), откроется http://localhost:8930/.
Открывать `index.html` напрямую нельзя: браузер блокирует модули и текстуры по `file://`.

## GitHub Pages
1. Создайте репозиторий и положите в его корень всё содержимое этой папки (вместе с `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты игра будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Сборка использует относительные пути, поэтому работает из любой подпапки.
Прогресс хранится в localStorage браузера.
